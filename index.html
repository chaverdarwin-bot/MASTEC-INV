☁️ MASTEC V61.2 · Nube y sincronización

🧩 Capa de nube preparada

V61.2 es local-first: tus datos actuales siguen funcionando en el navegador. La conexión de Supabase V61.1 no se elimina ni se modifica. Ahora MASTEC puede guardar la configuración de un segundo proveedor (Firebase) para usarlo como alternativa si Supabase continúa con el problema de DNS.

Supabase V61.1 conservado.
Firebase no se conecta ni cambia Supabase hasta que tú lo selecciones y configures.

Conecta MASTEC a tu base central

V61.1 ya viene preparada con la URL de tu proyecto. Solo debes colocar la Publishable key y crear/iniciar tu cuenta de nube. En esta primera etapa, los dispositivos pueden entrar con la misma cuenta. No uses una clave service_role en el navegador.

Sin conexión configurada.

🏢 Espacio de trabajo

V61.2 conserva la cuenta/espacio de Supabase de V61.1 y prepara una segunda vía con Firebase. La gestión de empleados, roles y permisos por usuario se ampliará después sin perder los datos locales.

🛡️ Recomendación

Antes de subir datos reales, crea un Respaldo V55. V61.2 mantiene el modo local y no borra la configuración de Supabase.

Supabase: la publishable/anon key puede estar en el navegador; la service_role nunca. Firebase: la configuración web es pública por diseño, pero los datos deben protegerse con Authentication y Firestore Security Rules.
